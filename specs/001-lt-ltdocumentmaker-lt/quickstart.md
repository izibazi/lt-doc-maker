# クイックスタートガイド: LT資料作成ツール

**作成日**: 2025-09-07  
**対象**: 開発者、QA、ステークホルダー  
**推定実行時間**: 15-20分  

## 概要

このガイドでは、LT資料作成ツールの主要機能を実際に体験できます。
開発環境での基本的な使用フローを通じて、システムの動作を確認します。

## 前提条件

### 必要な環境
- Node.js 20+
- PostgreSQL 15+
- Docker & Docker Compose
- Git

### セットアップ確認
```bash
node --version    # v20.0.0+
psql --version   # PostgreSQL 15+
docker --version # Docker 24+
```

## ステップ1: 環境構築

### 1.1 リポジトリのクローン
```bash
git clone <repository-url>
cd lt-doc-maker
```

### 1.2 依存関係のインストール
```bash
npm install
```

### 1.3 環境変数の設定
```bash
cp .env.example .env
```

`.env`ファイルを編集:
```env
# データベース
DATABASE_URL="postgresql://user:password@localhost:5432/lt_doc_maker"

# Next.js
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="your-secret-key"

# その他
NODE_ENV="development"
```

### 1.4 データベースの起動
```bash
docker-compose up -d postgres
```

### 1.5 データベースマイグレーション
```bash
npm run db:migrate
npm run db:seed
```

### 1.6 開発サーバーの起動
```bash
npm run dev
```

✅ **確認**: http://localhost:3000 でアプリケーションが起動することを確認

## ステップ2: 基本機能テスト

### 2.1 新規文書作成
1. ブラウザで http://localhost:3000 にアクセス
2. 「新規LT資料作成」ボタンをクリック
3. テンプレート選択画面で「技術プレゼン向け」を選択
4. 文書タイトルに「テストLT」と入力
5. 「作成開始」ボタンをクリック

✅ **期待値**: 文書作成画面に遷移し、選択したテンプレートが適用されている

### 2.2 コンテンツ入力
1. **導入セクション**:
   - 見出し: 「今日お話しすること」
   - 本文: 「新しい技術の紹介と活用方法について説明します」
   - 箇条書き: 「技術概要」「導入メリット」「実装例」

2. **メインポイント1**:
   - 見出し: 「技術概要」
   - 本文: 「この技術の特徴と従来技術との違いを解説します」
   - 箇条書き: 「高速処理」「メモリ効率」「開発体験向上」

3. **メインポイント2**:
   - 見出し: 「導入メリット」
   - 本文: 「プロジェクトに導入することで得られる具体的なメリット」
   - 箇条書き: 「開発速度向上」「保守性改善」「チーム生産性向上」

4. **まとめセクション**:
   - 見出し: 「まとめ」
   - 本文: 「この技術の導入を検討してみてください」
   - 箇条書き: 「検証推奨」「段階的導入」「チーム共有」

5. 「保存」ボタンをクリック

✅ **期待値**: 
- コンテンツが保存される
- 推定発表時間が「3m 45s」程度で表示される
- 文書ステータスが「作成中」になる

### 2.3 時間制限バリデーション
1. メインポイント3を追加:
   - 見出し: 「追加の詳細情報」
   - 本文: 非常に長いテキスト（2000文字程度）を入力
   - 箇条書きに10個以上のアイテムを追加

2. 「保存」ボタンをクリック

✅ **期待値**: 
- バリデーションエラーが表示される
- 「5分を超過しています（推定: 6m 20s）」のような警告が表示
- 改善提案が表示される

### 2.4 Markdownエクスポート
1. コンテンツを5分以内に修正
2. 文書ステータスを「完成」に変更
3. 「エクスポート」ボタンをクリック
4. 「Markdown（Notion互換）」を選択
5. 「エクスポート実行」をクリック

✅ **期待値**: 
- Notion互換のMarkdownファイルがダウンロードされる
- ファイル名が「テストLT_20250907.md」形式になる
- frontmatterにメタデータが含まれている

### 2.5 文書一覧表示
1. トップページに戻る
2. 「マイ文書」セクションを確認

✅ **期待値**: 
- 作成した「テストLT」が一覧に表示される
- ステータス、推定時間、作成日時が正しく表示される
- エクスポート回数が「1回」になっている

## トラブルシューティング

### よくある問題と解決策

**Q: データベース接続エラーが発生する**
A: 
1. PostgreSQLコンテナが起動しているか確認: `docker ps`
2. 接続情報が正しいか確認: `.env`ファイル
3. マイグレーションが実行済みか確認: `npm run db:migrate`

**Q: ページが404エラーになる**
A:
1. 開発サーバーが起動しているか確認: `npm run dev`
2. ポート3000が使用可能か確認: `lsof -i :3000`
3. Next.js の設定ファイル確認: `next.config.js`

**Q: テストが失敗する**
A:
1. テスト用データベースが設定済みか確認
2. 依存関係が最新か確認: `npm install`
3. 環境変数がテスト用に設定されているか確認

**Q: エクスポート機能が動作しない**
A:
1. ファイルダウンロードがブロックされていないか確認
2. ブラウザの設定を確認
3. コンテンツサイズが制限内か確認
