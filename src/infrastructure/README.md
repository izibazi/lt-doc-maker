# Infrastructure Layer

このディレクトリには、インフラストラクチャ層のコンポーネントを配置します。

## 構造

### database/
データベース関連の設定とマイグレーション
- `schema.ts` - Drizzle ORMスキーマ定義
- `connection.ts` - データベース接続設定
- `migrations/` - マイグレーションファイル

### repositories/
ドメインリポジトリの具体実装
- データベース操作の実装
- ドメインエンティティとの変換

## 原則

- 外部システムとの統合を担当
- ドメイン層のインターフェースを実装
- 技術的な詳細を隠蔽
